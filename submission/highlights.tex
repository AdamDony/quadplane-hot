\section*{Highlights}
\begin{itemize}
\item A history-conditioned transformer flies the rotor-wing hand-off of a plant family.
\item A context token resolves the plant while its response is inside the window.
\item A backup safety module certifies each command over a plant set with proofs.
\item One policy trained through a flight-identified differentiable model, no expert.
\item Compared with nine controllers, from recorded flight states and with PX4 in the loop.
\end{itemize}
